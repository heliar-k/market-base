# ADR 0004 — 多源共识层（市场风险卡 + 宏观环境卡）

**状态**：已接受
**日期**：2026-10-10

十个专题分析引擎（`*_analysis.py`）各说各话，站内没有「一眼看市场」的结论层。借鉴 BW Research 周报的三维共识框架（方向定于趋势、验证于结构、确认于资金），决定新增**共识层**：两级同构状态卡，由多成员投票合成单一状态标签。

## 决策

**两级卡，同一套规则引擎**（`src/consensus.py`）：

- **市场卡（风险轴）**：确认 risk-on / 确认 risk-off / 分歧。回答「现在能不能持有风险敞口」。
- **宏观卡（条件轴）**：确认宽松 / 确认紧缩 / 分歧。回答「环境条件在放水还是收水」。中性不设独立状态——票相持本质是信息不足，归入分歧，两卡保持同构。

**投票规则**（两卡共用）：

- 成员内部多子信号各自判 on/off/弃权，成员票 = 子信号多数，平票 → 成员弃权。
- 参与票 ≥2/3 同向 → 「确认」，否则「分歧」。
- 缺数据的成员剔除出分母，卡上标注 N/M 参与；缺席过半 → 整卡「数据不足」。
- **票龄 >2 个交易日算缺席**（周末顺延）——盘中临时值卡里 T+1 票照投，断更源自动退出。

**成员清单**（全部日更可得，不依赖本地 IBKR；COT 周频票龄过长，不进 v1）：

- 市场卡 6：趋势（SPX vs MA60+排列）、波动率（VIX 水平+期限斜率）、广度（ABV50）、信用（HY OAS 1M 变化）、期权结构（SPY net_gex）、卖空（SPY short ratio 5 日变化，proxy 级）。
- 宏观卡 6：政策路径（FOMC 概率）、净流动性 1M 变化、货币市场（SOFR−IORB）、曲线（2s10s 水平）、实际利率（DFII10 1M 变化）、财政（TGA 1M 变化）。宏观成员互相相关性高，是已知妥协，靠票面全展示对冲。

**时效与留痕**：daily-full（05:00）收盘定稿；intraday-refresh 重算但标「盘中临时值」。状态每日 upsert 进 `data/consensus/history.csv`（留痕不可回补，回测展示留 v2）。

**展示**：`/api/consensus` 预渲染 + 首页 SPA 状态卡（每张子票 ✔/✘/—/缺席可点，跳对应专题页）+ daily 简报一行。

## Considered Options

- **标的级交易信号**（技术+期权+资金共识 per symbol）：与 `sell_put.py` 现有交叉逻辑重叠，泛化它的增量最小。
- **方向轴**（确认偏多/偏空）：与「不构成投资建议」的站设有张力；风险轴不暗示交易。
- **子信号加权打分**：两层权重难解释；等权多数 + 全票面展示更诚实。
- **宏观卡 2×2 二维**（政策方向×流动性方向）：信息立体但首屏读不出单一结论。

## Consequences

- 新增 `src/consensus.py`（只读 CSV + 写 history.csv 的例外，同 bill_share 先例）；派生序列复用 `macro.py`，不重算。
- 每个成员的子信号阈值集中为模块顶部常量表（初值沿用各引擎既有 ZONES/分位口径，按数据分布校准），票面规则与代码同源可测。
- workflow：daily-full 与 intraday-refresh 各加一步 `uv run python -m src.consensus`（upsert 幂等，重复跑零风险）。
- 领域词汇进 CONTEXT.md（共识卡/成员/子信号/票龄/确认阈值）。
